# Public Asset System — Developer Guide

This document covers how to use, add, and maintain assets in `nexus-web`.

---

## Core Principle

**Never hardcode image paths in components.** All asset paths live in one place:

```
src/lib/constants/assets.ts
```

Import the `ASSETS` object and use its typed constants instead of string literals.

---

## Directory Structure

```
public/
├── branding/      GDG logos (SVG + WebP)
├── home/          Hero parallax layers, mascot illustration, bullet icon
├── about/         Benefits cards, Who-is-GDG mascots/decor, spiral
├── id/            GDG ID card page assets (spirals, card layers, decor)
├── team/          Team decorator images + all member photos
├── partners/      Sponsor/partner logos
└── auth/          Sparky, default avatar, signin screen assets
```

**Naming convention:** `[feature]-[subgroup]-[description].ext` (all lowercase kebab-case)

**Format rule:** Raster images → `.webp`. Vector logos/icons → `.svg`.

---

## Using an Asset in a Component

```tsx
import { ASSETS } from "@/lib/constants/assets";
import Image from "next/image";

// ✅ Correct
<Image src={ASSETS.BRANDING.GDG_LOGO_WEBP} alt="GDG Logo" width={40} height={40} />

// ❌ Never do this
<Image src="/branding/gdg-logo.webp" alt="GDG Logo" width={40} height={40} />
```

## Adding a New Asset

1. **Place the file** in the appropriate `public/<feature>/` folder using the naming convention: `[feature]-[subgroup]-[description].webp` (convert to WebP if raster).

2. **Add a constant** in `src/lib/constants/assets.ts` under the matching section:

    ```ts
    // Example: new team member
    TEAM: {
      WEB_DEVELOPMENT: {
        ...
        NEW_MEMBER_NAME: "/team/team-web-development-new-member-name.webp",
      },
    }
    ```

3. **Use the constant** in your component — never the raw string.

4. **Verify** the file exists at the declared path:

    ```bash
    npx tsx scripts/check-assets.ts   # or run the node one-liner:
    node -e "
      const fs = require('fs');
      const c = fs.readFileSync('src/lib/constants/assets.ts','utf-8');
      const missing = [...c.matchAll(/\"(\/[^\"]+\.(webp|svg|png|jpg))\"/g)]
        .map(m=>m[1]).filter(p=>!fs.existsSync('public'+p));
      missing.forEach(p=>console.log('MISSING:',p));
      console.log('Missing:',missing.length);
    "
    ```

## Converting Images to WebP

### Prerequisites: Install ffmpeg

The CLI uses `ffmpeg` under the hood. Install it once on your machine:

| OS | Command / Link |
|---|---|
| macOS | `brew install ffmpeg` |
| Ubuntu / Debian | `sudo apt install ffmpeg` |
| Windows | Download the latest build from [ffmpeg.org/download](https://ffmpeg.org/download.html) → **Windows builds from gyan.dev** → grab `ffmpeg-release-essentials.zip`. Extract it, then add the `bin/` folder to your **System PATH** (Control Panel → System → Advanced → Environment Variables → Path). Open a new terminal and verify with `ffmpeg -version`. |

---

### Running the CLI

From inside `apps/nexus-web/`:

```bash
pnpm run webp
```

No ffmpeg flags to memorize. Sparky walks you through everything. 🐶

---

### CLI Walkthrough

**Step 1 — Source files**

```
🖼️  What image(s) do you want to convert?
   Supported formats: .png, .jpg, .jpeg, .gif, .bmp, .tiff, .tif
   You can enter one file, multiple files (comma-separated),
   or a folder path to batch-convert all images inside it.

⚡🐶 Sparky is asking: File(s) or folder path: _
```

You can enter any of the following:

| Input | What happens |
|---|---|
| `my-photo.png` | Converts that single file |
| `photo1.jpg, photo2.png` | Converts both files |
| `downloads/team-photos/` | Batch-converts every supported image in the folder |

---

**Step 2 — Destination folder**

```
📂 Where should the converted file(s) be placed?
   (Folders inside public/)

  1. public/branding
  2. public/home
  3. public/about
  4. public/id
  5. public/team
  6. public/partners
  7. public/auth
  8. public/leaderboard
  9. public/sparky-points
  10. custom (type a path)

⚡🐶 Sparky is asking: Enter a number (1-10): _
```

Pick the matching feature folder. If a folder doesn't exist yet, pick **10** and type a path like `public/events` — it will be created automatically.

---

**Step 3 — Delete originals?**

```
⚡🐶 Sparky is asking: Delete original file(s) after conversion? (y/N): _
```

- `y` → source files are removed after a successful conversion (clean migration)
- `N` (default) → originals are kept alongside the new `.webp` files

---

**Step 4 — Confirm and convert**

```
📋 Conversion plan:
   Source files  : 3 image(s)
   Destination   : public/team
   Delete originals: no

⚡🐶 Sparky is ready! Proceed? (Y/n): y

⚡ Converting...

   ⚡ team-web-dev-gerald.png → team-web-dev-gerald.webp
   ⚡ team-web-dev-kyla.jpg → team-web-dev-kyla.webp
   ⚡ team-web-dev-carl.jpeg → team-web-dev-carl.webp

🎉 Successfully converted 3 file(s) to WebP!
📍 Location: public/team/

💡 Next steps:
   1. Add a constant in src/lib/constants/assets.ts
   2. Use ASSETS.<KEY> in your component — never the raw string
   3. Clear Next.js cache if replacing an existing asset: rm -rf .next
```

## After Moving or Renaming Assets

Always clear the Next.js cache before restarting — otherwise stale 404s will persist:

```bash
rm -rf .next && pnpm dev
```
